    rtm/vector4f.h¶

    #include "rtm/vector4f.h"

    vector_set¶

    vector4f vector_set(float x, float y, float z, float w)

    Creates a vector4 from all 4 components.

    vector4f vector_set(float x, float y, float z)

    Creates a vector4 from the [xyz] components and sets [w] to 0.0.

    vector4f vector_set(float xyzw)

    Creates a vector4 from a single value for all 4 components.

    vector_zero¶

    vector4f vector_zero()

    Returns a vector consisting of all zeros.

    The return value also converts to vector4d.

    vector_coord_forward¶

    vector4f vector_coord_forward()

    Returns a unit vector pointing in the forward direction of the default coordinate system (Z+).

    The return value also converts to vector4d.

    vector_coord_up¶

    vector4f vector_coord_up()

    Returns a unit vector pointing in the up direction of the default coordinate system (Y+).

    The return value also converts to vector4d.

    vector_coord_cross¶

    vector4f vector_coord_cross()

    Returns a unit vector pointing in the cross direction of the default coordinate system (X+).

    The return value also converts to vector4d.

    vector_as_scalar¶

    float vector_as_scalar(vector4f input)

    Coerces an vector4 input into a scalar by grabbing the first SIMD lane.

    The return value also converts to scalarf.

    vector_ceil¶

    vector4f vector_ceil(vector4f input)

    Per component returns the smallest integer value not less than the input (round towards positive infinity). vector_ceil([1.8, 1.0, -1.8, -1.0]) = [2.0, 1.0, -1.0, -1.0]

    vector_floor¶

    vector4f vector_floor(vector4f input)

    Per component returns the largest integer value not greater than the input (round towards negative infinity). vector_floor([1.8, 1.0, -1.8, -1.0]) = [1.0, 1.0, -2.0, -1.0]

    vector_lerp¶

    vector4f vector_lerp(vector4f start, vector4f end, float alpha)
vector4f vector_lerp(vector4f start, vector4f end, vector4f alpha)

    Per component linear interpolation of the two inputs at the specified alpha. The formula used is: ((1.0 - alpha) * start) + (alpha * end). Interpolation is stable and will return 'start' when alpha is 0.0 and 'end' when it is 1.0. This is the same instruction count when FMA is present but it might be slightly slower due to the extra multiplication compared to: start + (alpha * (end - start)).

    vector_eerp¶

    vector4f vector_eerp(vector4f start, vector4f end, float alpha)
vector4f vector_eerp(vector4f start, vector4f end, vector4f alpha)

    Per component exponential interpolation of the two inputs at the specified alpha. The formula used is: start * (end / start)^alpha. For equal steps of alpha, the result changes by the same ratio. Use it to interpolate a scale. The result is 'start' when alpha is 0.0. It is approximately 'end' when alpha is 1.0. The two inputs must have the same sign and must not be zero. Otherwise, the result is undefined.
