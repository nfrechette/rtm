    rtm/version.h¶

    #include "rtm/version.h"

    In order to allow multiple versions of this library to coexist side by side within the same executable/library, the symbols have to be unique per version. We achieve this by using a versioned namespace that we optionally inline. To disable namespace inlining, define RTM_NO_INLINE_NAMESPACE before including any Realtime Math header. To disable the versioned namespace altogether, define RTM_NO_VERSION_NAMESPACE before including any Realtime Math header.

    RTM_VERSION_MAJOR¶

    #define RTM_VERSION_MAJOR 2

    The major version of Realtime Math.

    RTM_VERSION_MINOR¶

    #define RTM_VERSION_MINOR 4

    The minor version of Realtime Math.

    RTM_VERSION_PATCH¶

    #define RTM_VERSION_PATCH 99

    The patch version of Realtime Math.
