    scalar_floor¶

    float scalar_floor(float input)

    Returns the largest integer value not greater than the input (round towards negative infinity). scalar_floor(1.8) = 1.0 scalar_floor(-1.8) = -2.0

    scalar_ceil¶

    float scalar_ceil(float input)

    Returns the smallest integer value not less than the input (round towards positive infinity). scalar_ceil(1.8) = 2.0 scalar_ceil(-1.8) = -1.0

    constexpr float scalar_neg_mul_sub(float s0, float s1, float s2)

    Returns the negative multiplication/subtraction of the three inputs: -((s0 * s1) - s2) This is mathematically equivalent to: s2 - (s0 * s1)

    scalar_lerp¶

    float scalar_lerp(float start, float end, float alpha)

    Returns the linear interpolation of the two inputs at the specified alpha. The formula used is: ((1.0 - alpha) * start) + (alpha * end). Interpolation is stable and will return 'start' when alpha is 0.0 and 'end' when it is 1.0. This is the same instruction count when FMA is present but it might be slightly slower due to the extra multiplication compared to: start + (alpha * (end - start)).

    scalar_exp¶

    float scalar_exp(float input)

    Returns the natural exponential of the input: e^input. The function uses the same algorithm as vector_exp(..): for the same input, the results are equal.

    scalar_log¶

    float scalar_log(float input)

    Returns the natural logarithm of the input. The function uses the same algorithm as vector_log(..): for the same input, the results are equal. The result is -inf when the input is zero, and NaN when the input is negative.

    scalar_eerp¶

    float scalar_eerp(float start, float end, float alpha)

    Returns the exponential interpolation of the two inputs at the specified alpha. The formula used is: start * (end / start)^alpha. For equal steps of alpha, the result changes by the same ratio. Use it to interpolate a scale. The result is 'start' when alpha is 0.0. It is approximately 'end' when alpha is 1.0. The two inputs must have the same sign and must not be zero. Otherwise, the result is undefined.

    scalar_round_symmetric¶

    float scalar_round_symmetric(float input)

    Returns the rounded input using a symmetric algorithm. scalar_round_symmetric(1.5) = 2.0 scalar_round_symmetric(1.2) = 1.0 scalar_round_symmetric(-1.5) = -2.0 scalar_round_symmetric(-1.2) = -1.0

    scalar_round_bankers¶

    float scalar_round_bankers(float input)

    Returns the rounded input using banker's rounding (half to even). scalar_round_bankers(2.5) = 2.0 scalar_round_bankers(1.5) = 2.0 scalar_round_bankers(1.2) = 1.0 scalar_round_bankers(-2.5) = -2.0 scalar_round_bankers(-1.5) = -2.0 scalar_round_bankers(-1.2) = -1.0

    scalar_sincos¶

    vector4f scalar_sincos(float angle)

    Returns both sine and cosine of the input angle. The result's [x] component contains sin(angle). The result's [y] component contains cos(angle). [zw] are undefined.

    void scalar_sincos(float angle, float& out_sin, float& out_cos)

    Returns both sine and cosine of the input angle.

    scalar_asin¶

    float scalar_asin(float value)

    Returns the arc-sine of the input. Input value must be in the range [-1.0, 1.0].

    scalar_acos¶

    float scalar_acos(float value)

    Returns the arc-cosine of the input. Input value must be in the range [-1.0, 1.0].

    scalar_tan¶

    float scalar_tan(float angle)

    Returns the tangent of the input angle.

    scalar_atan¶

    float scalar_atan(float value)

    Returns the arc-tangent of the input. Note that due to the sign ambiguity, atan cannot determine which quadrant the value resides in. See scalar_atan2.

    scalar_atan2¶

    float scalar_atan2(float y, float x)

    Returns the arc-tangent of [y/x] using the sign of the arguments to determine the correct quadrant. Y represents the proportion of the y-coordinate. X represents the proportion of the x-coordinate.
