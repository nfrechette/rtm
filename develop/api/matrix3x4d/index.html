    matrix_mul¶

    matrix3x4d matrix_mul(matrix3x4d lhs, matrix3x4d rhs)

    Multiplies two 3x4 affine matrices. Multiplication order is as follow: local_to_world = matrix_mul(local_to_object, object_to_world)

    matrix_mul_point3¶

    vector4d matrix_mul_point3(vector4d point, matrix3x4d_argn mtx)

    Multiplies a 3x4 affine matrix and a 3D point. Multiplication order is as follow: world_position = matrix_mul(local_position, local_to_world)

    matrix_mul_vector3¶

    vector4d matrix_mul_vector3(vector4d vec3, matrix3x4d_argn mtx)

    Multiplies a 3x4 affine matrix and a 3D vector. Multiplication order is as follow: world_position = matrix_mul(local_vector, local_to_world) Note: The proper way to transform a normal by an affine matrix with non-uniform scale is to multiply the normal with the cofactor matrix of the 3x3 rotation/scale part. See: https://github.com/graphitemaster/normals_revisited

    matrix_transpose¶

    matrix3x3d matrix_transpose(matrix3x4d input)

    Transposes a 3x4 affine matrix. Note: This transposes the upper 3x3 rotation/scale part of the matrix and it discards the translation. This is because a transposed 4x4 affine matrix is no longer affine due to its last row no longer being [0, 0, 0, 1]. The most common usage of an affine transpose operation is to construct the inverse transpose used to transform normal bi-vectors.

    matrix_inverse¶

    matrix3x4d matrix_inverse(matrix3x4d input)

    Inverses a 3x4 affine matrix. If the input matrix is not invertible, the result is undefined. For a safe alternative, supply a fallback value and a threshold.

    matrix3x4d matrix_inverse(matrix3x4d input, matrix3x4d_argn fallback, double threshold=1.0E-8)

    Inverses a 3x4 affine matrix. If the input matrix has a determinant whose absolute value is below the supplied threshold, the fall back value is returned instead.

    matrix_determinant¶

    scalard matrix_determinant(matrix3x4d input)

    Returns the determinant of the 3x3 rotation/scale part of the input 3x4 matrix.

    matrix_minor¶

    scalard matrix_minor(matrix3x4d input, axis3 row, axis3 column)

    Returns the minor of the 3x3 rotation/scale part of the input 3x4 matrix. See: https://en.wikipedia.org/wiki/Minor_(linear_algebra) The minor is the determinant of the sub-matrix input when the specified row and column are removed.

    matrix_cofactor¶

    matrix3x3d matrix_cofactor(matrix3x4d input)

    Returns the cofactor matrix of the 3x3 rotation/scale part of the input 3x4 matrix. See: https://en.wikipedia.org/wiki/Minor_(linear_algebra)#Cofactor_expansion_of_the_determinant Note: The proper way to transform a normal by an affine matrix with non-uniform scale is to multiply the normal with the cofactor matrix of the 3x3 rotation/scale part. See: https://github.com/graphitemaster/normals_revisited

    matrix_adjugate¶

    matrix3x3d matrix_adjugate(matrix3x4d input)

    Returns the adjugate of the input matrix. See: https://en.wikipedia.org/wiki/Adjugate_matrix

    matrix_remove_scale¶

    matrix3x4d matrix_remove_scale(matrix3x4d input)

    Removes the 3D scale from a 3x4 affine matrix. Note that if the scaling is 0.0 for a particular axis, the original rotation axis cannot be recovered trivially and no attempt is done to do so. In theory, we could use the other axes to try and recover it.
